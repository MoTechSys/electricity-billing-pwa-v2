# ملاحظات عمر على التصميم — Design Feedback

تاريخ البدء: 2026-06-09
المرجع البصري: تطبيق جوال dark-mode (شبكة كروت 2×2 مربّعة + شريط تنقّل سفلي + شعار).
الصورة المرجعية محفوظة: docs/ref-mobile-design.jpg

## الملاحظات

### 1. شكل الكروت الإحصائية في الصفحة الرئيسية
- **المطلوب:** الكروت تظهر **شبكة مربّعات 2×2** (مثل الصورة المرجعية) — مش طولية (عمود واحد) كما هي الآن بعد إصلاح الجوال.
- الكروت في الصورة: مربّعة، الأيقونة أعلى يمين/أعلى، الرقم كبير، التسمية تحت.
- الحالة: ⏳ بانتظار باقي الملاحظات قبل التنفيذ.

### 2. شريط التنقّل السفلي (Bottom Nav) في وضع الهاتف
- **المطلوب:** استبدال القائمة/الشريط الجانبي في الجوال بـ **شريط تنقّل سفلي عائم (floating bottom bar)** بستايل فخم:
  - خلفية داكنة (dark) بحواف دائرية كبيرة (pill/rounded) + ظل، عائم فوق أسفل الشاشة (مش ملاصق للحافة).
  - **زر وسطي بارز دائري ذهبي** (مرفوع لأعلى قليلاً) — أيقونة شبكة (☷) = "القائمة".
  - بقية العناصر: أيقونة + تسمية تحتها (مثل: الرئيسية 🏠، خدماتنا، المعرض، من نحن).
  - **اللون الذهبي** للعنصر النشط + لمسات ذهبية (gold accent على خلفية داكنة).
- المرجع البصري: docs/ref-bottom-nav.jpg
- الحالة: ⏳ بانتظار باقي الملاحظات قبل التنفيذ.

### 3. ستايل الأزرار والبوتونات (Buttons)
- **المشكلة:** كل الأزرار حالياً تصميمها مسطّح/فاضي (flat) وغير واقعي/حقيقي.
- **المطلوب:** تصميم **فخم واقعي** لكل الأزرار: عمق (depth)، ظلال (shadows)، تدرّجات (gradients)، لمسات ذهبية/فخمة، تأثيرات hover/press واقعية (مثل الأزرار في الصور المرجعية).
- الحالة: ⏳ بانتظار باقي الملاحظات قبل التنفيذ.

### 4. تصميم الفاتورة عند التصدير/الطباعة (Invoice PDF/Print)
- **المشكلة:** شكل الفاتورة الحالي عند التصدير سيئ جداً.
- **المطلوب:** عمر صمّم شكل جديد للفاتورة وسيرسل:
  - ملف **HTML** للتصميم الجديد.
  - + البرومبت/الشرح الكامل (لفهم المطلوب).
- **التنفيذ:** استبدال قالب تصدير الفاتورة الحالي (route: /api/invoices/[id]/pdf) بالتصميم الجديد مع ربط بيانات الفاتورة الحقيقية (placeholders).
- الحالة: ⏳ بانتظار ملف HTML + البرومبت من عمر.
