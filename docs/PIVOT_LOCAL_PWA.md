# قرار التحوّل: PWA محلي بالكامل (بدون باك-إند)

تاريخ: 2026-06-09 | القرار من عمر (تسجيلات صوتية).

## القرار النهائي
- التطبيق = **PWA** يُثبّت على جوال الشخص.
- **قاعدة البيانات تُخزّن في الجهاز نفسه** (IndexedDB) — لا سيرفر، لا مزامنة، كل جهاز مستقل.
- **بدون باك-إند**: إزالة Prisma + API routes + Puppeteer + JWT server auth.
- توليد الفاتورة PDF **داخل المتصفح** (مكتبة client-side) بنفس التصميم A4 الفاخر.
- النشر على **Vercel** (static/SSG، فرونت فقط).
- يبقى يعمل **offline** بالكامل.
- ✅ **نسخ احتياطي**: تصدير قاعدة البيانات كملف يُحفظ في الجهاز + استيرادها (للأمان والنقل بين الأجهزة).

## ما يُلغى (التقرير المعقّد مرفوض)
- لا PostgreSQL، لا RLS، لا multi-tenant، لا الطبقات العشر، لا الأمان الخادمي المعقّد.
- لا نظام مستخدمين متعدد بعزل خادمي (لأنه بلا سيرفر).

## المخزّن المحلي (Data layer)
- **IndexedDB** عبر Dexie.js — تخزّن: subscribers, invoices, settings.
- **تصدير**: زر يصدّر كل البيانات كملف JSON (نسخة احتياطية) يُحفظ في الجهاز.
- **استيراد**: زر يستورد ملف JSON ويستعيد البيانات.

## الفاتورة (PDF client-side)
- نفس تصميم invoice.html الفاخر (A4 landscape، شعار CSS، Cairo).
- التوليد: html → PDF داخل المتصفح (يُحدّد الأنسب للعربي RTL عند التنفيذ).

## الخطة
1. هيكلة client-only: حذف /api، Prisma، puppeteer.
2. طبقة بيانات Dexie (db.ts).
3. تحويل الصفحات (dashboard, subscribers, invoices, settings) لتقرأ/تكتب من Dexie.
4. توليد PDF client-side.
5. تصدير/استيراد قاعدة البيانات (نسخة احتياطية بالجهاز).
6. PWA offline كامل.
7. نشر Vercel.
