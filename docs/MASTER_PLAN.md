# الخطة المتكاملة — Master Plan (نظام Motech لفواتير الكهرباء)

تاريخ: 2026-06-09 | المنفّذ: Clow2 | الحالة: قيد التنفيذ
الهدف: تطبيق PWA فاخر، متكامل، حسب المعايير، متعدّد المستخدمين بعزل بيانات.

## 1) معمارية قاعدة البيانات (Prisma + SQLite → قابل للترقية لـ PostgreSQL)

### تعديلات/إضافات على الجداول
- **User** (موجود): + `email?`, `phone?`, `avatarColor?` (للملف الشخصي). الأدوار: `admin` | `clerk`.
- **Subscriber**: + `createdById` (FK→User) + index. (عزل البيانات)
- **Invoice**: تفعيل `issuedById` (يُعبّأ بالمستخدم الحالي). + index على (issuedById, createdAt).
- **AuditLog** (موجود): تفعيله فعلياً — يُكتب عند كل create/update/delete/login.
- **Setting** (موجود): إعدادات عامة (سعر افتراضي، اسم الشركة...).

### مبدأ العزل (Owner-based isolation)
- `admin` → يرى كل شيء.
- `clerk` → يرى فقط: `Subscriber.createdById == me` و `Invoice.issuedById == me`.
- يُطبّق في كل API (GET list / GET one / mutations).

## 2) الميزات
| الميزة | الوصف | الوصول |
|--------|--------|--------|
| إدارة المستخدمين | إضافة/تعطيل/حذف/تعديل موظفين | admin |
| سجل النشاط | عرض كل العمليات بالتاريخ + الفاعل | admin |
| الملف الشخصي | بيانات المستخدم + تغيير كلمة المرور | الكل |
| كشف الحساب | لمشترك/عدّة مشتركين، عمليات بالتاريخ، طباعة | admin + (clerk لعملائه) |
| عزل البيانات | كل موظف يرى ما أنشأه فقط | تلقائي |

## 3) الواجهة (UX فاخر)
- **استايل عام فاخر**: خلفية متدرّجة راقية (مو أبيض)، بطاقات بعمق، لمسات ذهبية/كحلي، خط Cairo.
- **لوحة التحكم**: حذف زر الفاتورة العلوي، كروت إحصائية **3×2** أصغر، **رسم بياني** صغير تحتها (فواتير/استهلاك آخر فترة).
- **الفوتر/الشريط السفلي**: تحسين التناسق، **الزر الأوسط** يفتح **قائمة فاخرة** (sheet منبثق بأنيميشن) فيها: إصدار فاتورة، عميل جديد، كشف حساب، (للأدمن: مستخدمين، نشاط).
- **اختيار العميل**: أيقونة علوية صغيرة → قائمة منبثقة (بحث + بطاقات: رقم-اسم(هاتف)+مبلغ مستحق أحمر) — على نمط نظام التحصيل المرجعي.
- **PWA**: يبقى تطبيق ويب تقدّمي (manifest+SW شغّالين).

## 4) مراحل التنفيذ
- **A — DB & Backend**: schema + migration + APIs (users, isolation, audit, statement). مع الحفاظ على نفس signatures.
- **B — UI/UX الفاخر**: globals theme، لوحة التحكم 3×2 + chart، الفوتر + قائمة الزر الأوسط، اختيار العميل.
- **C — صفحات جديدة**: /users، /activity، /profile، /statement.
- **D — اختبار شامل**: build + login بكل دور + عزل + إصدار فاتورة + كشف حساب + PDF.

## 5) المعايير
- لا كسر للوظائف الحالية. commits منظّمة. توثيق. اختبار فعلي لكل مرحلة.
- البيانات الحالية (اختبار) → تُنسب للأدمن أو تُمسح بنظافة عند الـmigration.
