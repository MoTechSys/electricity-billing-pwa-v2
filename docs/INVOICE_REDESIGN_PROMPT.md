# برومبت إعادة تصميم الفاتورة (من معين العباسي عبر عمر)

## الملف المستهدف
- `src/lib/pdf-generator.ts` (رئيسي)
- `src/lib/invoice-images.ts` (لو لزم)
- ملف مرجعي مرفق: `invoice.html` (التصميم النهائي الكامل HTML+CSS+Logo) — بانتظار استلامه.

## السياق
Next.js 16 + Prisma + SQLite + Puppeteer + Tailwind 4. الوظائف كلها شغّالة.
المطلوب: تحديث تصميم الفاتورة المُولّدة (PDF + معاينة الشاشة) لتطابق التصميم الجديد 100% **بدون المساس بأي logic أو DB**.

## جدول الفروقات
| الجانب | الحالي | المطلوب |
|---|---|---|
| مقاس الورقة | Letter | **A4 Landscape** (297×210mm) |
| الرأس | صورة banner + logo دائري صغير | صندوق برأس + شعار دائري double-ring |
| اسم الشركة | داخل صورة banner | نص مباشر يمين الرأس |
| لون العنوان | #0000FF بخط تحته | **#0e10b3 بدون خط** |
| الجدول | بدون فواصل آلاف | **مع فواصل آلاف (173,732.00)** |
| المبلغ كتابة | داخل الجدول | **خارج الجدول** (بلوك مستقل) |
| الذيل | بدون خط فاصل | **بخط أفقي فاصل** |

## التغييرات التفصيلية

### 1. مقاس الورقة
- `@page { size: A4 landscape; margin: 10mm 15mm; }`
- `page.pdf({ format: 'A4', landscape: true, ... })`

### 2. الرأس (استبدال banner image بصندوق HTML/CSS)
- صندوق حدود رقيقة سوداء + زوايا دائرية 10px، 3 أعمدة grid:
  - **يمين:** اسم الشركة نص سطرين: "شركة العباسي" (عريض 20pt) + "لتوليد الطاقة الكهربائية"
  - **وسط:** شعار دائري CSS 70×70px، حلقة برتقالية مزدوجة: `border:3px solid #d5802b` + `box-shadow: inset 0 0 0 1.5px #fff, inset 0 0 0 3.5px #d5802b`، بداخله رمز برق SVG بلون #232d62
  - **يسار:** فارغ

### 3. العنوان الرئيسي
- "فاتورة استهلاك كهرباء"، لون **#0e10b3**، بدون underline، حجم 26px، وزن 800.

### 4. تنسيق الأرقام (فواصل آلاف)
```ts
n.toLocaleString('en-US', { minimumFractionDigits: 2, maximumFractionDigits: 2, useGrouping: true })
```
النتيجة: `173,732.00`.

### 5. ألوان الجدول
- رأس الجدول: `background: #fcd5b4`
- المبلغ المستحق: `color: #1f9cf0` وزن 800 حجم 17pt
- باقي الخلايا: وزن 600

### 6. "المبلغ المستحق كتابةً" — بلوك مستقل تحت الجدول
```html
<div class="written-amount"><span class="lbl">المبلغ المستحق كتابةً هو :-</span> ${invoice.netDueWords}</div>
```

### 7. الذيل (Footer)
- خط أفقي فاصل فوق الذيل: `border-top: 1.5px solid #000; padding-top: 12px;`
- يمين: الملاحظة لون #0e10b3 وزن 700 | يسار: "الحسابات" أسود وزن 800
- خط سفلي: `border-bottom: 2px solid #000`

### 8. الخط
- Cairo من Google Fonts: `family=Cairo:wght@400;600;700;800;900`
- `font-family: 'Cairo', Tahoma, Arial, sans-serif;`

### 9. أعمدة الجدول (colgroup نسب)
- القراءة السابقة/الحالية/الاستهلاك: 11.5% لكل
- القيمة: 14% | خدمات/المتأخرات: 8% لكل | مدفوع خلال الفترة: 14% | المبلغ المستحق: 14%
